## 怎么用

- **想理解一个概念**：在 `concepts/` 里找到对应条目。每条包括自写讲解、值得读的年份，以及对应的体检题编号。
- **想检查自己的生意或决策**：打开 [生意体检题](checklist/business-checkup.md)，逐题自己回答。题目只帮助整理思路，不给结论、不打分、不估值。
- **想读原文**：按条目里写的年份，到伯克希尔官网的股东信栏目阅读英文原信（见下文「出处」）。
