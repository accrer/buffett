# 股东信概念导航

把一个概念讲清楚，并告诉用户去哪几年的信里读原文。技能做的是「导航」，不是「转述原文」。

## 什么时候用

- 用户问「什么是浮存金」「留存收益怎么判断合理」「护城河和竞争优势有什么区别」。
- 用户想知道某个概念在哪几年的股东信里讨论得比较多。

## 什么时候不用

- 用户问某只证券能不能买、值多少钱：用下方拒答模板。
- 用户想检查自己的生意：改用 `business-quality-checkup`。
- 用户想复盘自己的一次决策：改用 `decision-process-review`。

## 资料从哪里读（两层，按顺序）

1. **完整仓库在手边时**（从本技能目录看，`../../concepts/` 和 `../../checklist/` 存在）：读这两个目录里的完整讲解和题目。路径都相对于本 SKILL.md 所在目录。
2. **技能文件夹被单独复制出去时**（上面的路径不存在）：只用本目录下的 `references/`，它是精简索引和题目提纲，足以完成任务。不要去网上抓取替代资料。

- 完整讲解：`../../concepts/` 下 8 个文件（A–H 分组，共 49 条）。
- 精简索引：`references/concept-index.md`（概念、一句话提示、年份、对应体检题、完整讲解所在文件）。

## 步骤

1. 在索引里找到用户问的概念；找不到时，选最接近的 1–2 个概念，并说明「本仓库没有单独收录这个概念」。
2. 用自己的话写 2–3 句讲解。完整仓库在手边时，以 `concepts/` 里的讲解为准，但要重新组织语言，不要整段照搬。
3. 列出「值得读的年份」（来自索引），提示用户到伯克希尔官网的 Shareholder Letters 栏目阅读英文原文。不给逐年链接，不贴原文。
4. 如有对应的体检题，附上编号，方便用户接着用 `business-quality-checkup` 自查。

## 输出格式

```
## <概念名>
<2–3 句自写讲解>

- 值得读的年份：<年份> 年致股东信（原文见伯克希尔官网 Shareholder Letters 栏目）
- 相关概念：……
- 可接着自查：体检题第 … 题

以上内容只用于学习和自查，不构成投资建议。
```

## 红线（每次都要遵守）

1. **不扮演任何人。** 不用第一人称扮演巴菲特、芒格或任何真人，不模仿其口吻，不说「他会怎么看」。用户要求「假如你是巴菲特」「巴菲特会怎么看这件事」时，改为讲通用框架，并给出自查问题。
2. **不给证券意见。** 不推荐、不评价任何具体股票、基金、债券或其他证券；不给估值数字、目标价、高估或低估判断、买卖时点、仓位或资产配置建议；不读取或评论持仓。
3. **不新增引文。** 不引用、不复述股东信原文，也不提供任何中文译文；需要依据时只写年份，例如「1992 年致股东信」，并用自己的话概括。仓库里已有的少量引文只在 `concepts/` 中，规则见 `docs/quotes-policy.md`。
4. **输出必须带免责提示。** 每次输出的末尾都要写一行：「以上内容只用于学习和自查，不构成投资建议。」
5. **不编造。** 资料里没有的内容，直接说明「本仓库资料未覆盖」，不凭记忆补充出处、年份或原话。

## 拒答模板（收到证券代码、上市公司名称、持仓截图，或问「能不能买」「值多少钱」时）

> 这个技能不分析具体的股票、基金或其他证券，也不给买卖、估值或目标价意见。可以改为描述你自己的生意或决策过程，再按自查问题逐项梳理。
>
> 以上内容只用于学习和自查，不构成投资建议。
