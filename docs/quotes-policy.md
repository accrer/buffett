# 引文规则与位置索引

本仓库以自写内容为主，只在少数地方用英文短引来说明问题。为避免把引文汇编成可以替代原文的「语录集」，**本页不重复引文原文**，只列规则和每条引文所在的位置。

## 规则

1. 每封股东信最多引 1 句，每句不超过 40 个英文单词；不拼接，不用省略号把两句连成一句。
2. 不引被广泛单独传播的招牌金句，不引全信最核心的段落，不引信中的第三方材料（别人的文章、图表、引语）以及表格和财务数据。
3. 每条引文用 Markdown 引用块（`>`）与自写内容分开，写明年份和出处，并紧跟一段仓库作者自写的评述，篇幅为引文的 2–3 倍。
4. 引文逐字照录，不改词；每条都已对照伯克希尔官网发布的原文核对。拿不准原话的，一律不引，改为用自己的话转述。
5. 不提供引文的中文译文，也不使用任何第三方中文译文。正文中的中文讲解都是仓库作者的转述和概括。
6. **引文不在本仓库的开源许可范围内**（见 [LICENSE.md](../LICENSE.md)）。
7. 文中出现的一般财经术语（如内在价值、安全边际、护城河）是通用概念，不属于引文。

## 关于出处

- 1977 年以后的致股东信可在伯克希尔官网的 Shareholder Letters 栏目找到；本仓库只在 README 放一个指向该栏目索引页的总链接，正文出处只写文字，不做逐年链接。
- 1965–1976 年的股东信和合伙人时期的信不在该栏目中。笔记里提到合伙人时期的内容时，只作概括，不引原文，英文出处未核。
